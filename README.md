# VK Poster

Панель для предложений объявлений в VK от личного профиля: текст, фото плитками
или каруселью, группы, расписание, операторы, администрирование и проверка
опубликованных записей. Работает через официальный VK ID/API, без браузера VK.

## Развёртывание одной командой

Нужны Git и запущенный Docker с Compose v2 (Linux: Docker Engine;
macOS/Windows: Docker Desktop или совместимый runtime). Python устанавливать не нужно.

Linux / macOS:

```sh
git clone https://github.com/Trixter619/Poster.git && cd Poster && ./deploy.sh
```

Windows, PowerShell:

```powershell
git clone https://github.com/Trixter619/Poster.git; if ($LASTEXITCODE -eq 0) { Set-Location Poster; ./deploy.ps1 }
```

Установка соберёт контейнер, предложит создать первого администратора и запустит
бота в фоне. Пароль вводится скрыто. Открой http://localhost:8787.
Повторный запуск команды сохраняет аккаунты, фото, подключения и расписания.
Сервис автоматически поднимается после перезапуска Docker.

## Новый сервер с HTTPS

До установки направь DNS домена на сервер и открой входящие порты 80/443.
Скопируй `.env.example` в `.env` и укажи `DOMAIN` и `VKID_APP_ID`.
В настройках своего приложения VK ID добавь callback:
`https://ТВОЙ-ДОМЕН/auth/vk/callback`. Приложению и токену нужны права `wall photos`.
Это настройка у VK, которую установка бота сама выполнить не может.

Затем одна команда:

```sh
./deploy.sh --public
```

Windows: `./deploy.ps1 -Public`. Caddy автоматически выдаст и продлит сертификат.
Панель будет доступна по `https://ТВОЙ-ДОМЕН`; бот продолжит работать, когда твой
компьютер выключен, если сервер и Docker работают.

Локальный запуск тоже требует разрешённого VK callback. `.env` позволяет задать
`VKID_CALLBACK_URL`; адрес должен быть зарегистрирован в приложении VK ID.
Если VK требует HTTPS, используй публичный вариант с доменом. Сам запуск
локальной панели не выдаёт разрешения VK и не переносит старый аккаунт автоматически.

## Подключение и работа

1. Войди администратором, созданным установкой.
2. В «Подключение VK» войди нужным **личным профилем** и разреши `wall photos`.
3. Загрузи объявление и фото, добавь группы, нажми «Проверить доступ».
4. Проверь первую отправку, затем включи нужные расписания и сними общую паузу.

Проверка учитывает `can_suggest`. Прямую публикацию (`can_post=1`) бот не выполняет
в режиме предложения. Возможности API и ручной кнопки VK могут отличаться.
При расхождении сначала сверяй конкретный ID подключённого профиля.
Загрузка фото повторяется при временных сбоях; неопределённая отправка записи
не повторяется автоматически. Публичная стена проверяется каждые 15 минут;
поиск сопоставляет сохранённый текст, число фото и время, допускает смену номера
записи после модерации, но не выбирает наугад среди нескольких совпадений.
Общая пауза останавливает и расписания, и автоматические проверки.

Администратор одобряет заявки операторов и управляет ролями через /admin.
Пароль можно изменить в /account; восстановление — заявка и одноразовая ссылка
от другого администратора. Последнего администратора снять нельзя.
Названия групп в панели можно менять независимо от VK.

## Данные и обновление

Git содержит код; учётные записи, токены, пароли, фото и рабочая история в него
не входят. Docker хранит данные в томе `poster_data`. Повторная установка — новая
чистая инсталляция; перенос существующих данных делай отдельно по защищённому каналу.
Не запускай две копии с одними активными расписаниями: возможны двойные отправки.

Обновление локальной установки:

```sh
git pull --ff-only && ./deploy.sh
```

На публичном сервере используй `./deploy.sh --public`. Перед обновлением дождись
окончания отправки и поставь автоматику на паузу. Обновление не включает её само.

Логи: `docker compose logs --tail=100 app`.
Остановка: `docker compose stop`. Не используй `down -v`, если нужны сохранённые данные.
Для публичного варианта команды обслуживания запускай с
`docker compose -f compose.yaml -f compose.public.yaml`.

Без Docker: Linux/macOS `./start.sh`, Windows `Start VK Poster.cmd`.
Этот режим устанавливает Python через uv и держит бот запущенным в терминале.
Настройки передаются переменными окружения; `.env` в этом режиме не загружается.

## Проверки

```sh
.runtime/venv/bin/python -m unittest discover -s tests -q
```

Браузерные регрессии требуют Chromium: `python -m playwright install chromium`.
Рабочему API-сервису Chromium не нужен. Тесты используют временные данные и моки;
они не публикуют реальные объявления в VK.
